GST Outward and Inward Summary (India)

A period GST summary by rate, by state and by HSN, for checking before you file

Pick a period and a company, press Compute, and read three tables back: outward supplies, inward supplies and an HSN summary. It is the working paper you want open next to the return before you press submit — a place to see, in one screen, what the books say the period contained.

The period summary, Outward Supplies tab: four rate and place of supply buckets on 490,000.00 of taxable value, splitting out 13,800.00 CGST, 13,800.00 SGST and 50,100.00 IGST. The banner says plainly that this is a check before you file, not a return.

The HSN Summary tab of the same window: inward and outward lines by HSN or SAC code with description, UQC, quantity, GST rate, taxable value and the tax split, totalling 1,290,000.00 over 25 units.

What it does

Outward supplies by rate and state

Taxable value, CGST, SGST, IGST and cess bucketed by the combined GST rate and by place of supply, with intra-state and inter-state separated.

Inward supplies

The same breakdown for vendor bills and debit notes, so purchase tax can be checked with the same eye as sales tax.

HSN summary

HSN/SAC code, description, UQC, quantity, taxable value and tax per rate, aggregated across the whole period.

Reconciliation totals

Period figures grouped the way GSTR-3B table 3.1(a) and the GSTR-1 registered/unregistered split present them, so a difference shows up as a number rather than a hunch.

Drill-down to the invoices

Every row opens the documents it was built from. A figure that looks wrong is traced to the invoice in two clicks.

Export

XLSX when the standard xlsxwriter library is present, CSV otherwise. No extra Python package is ever installed.

Good to know

  • This is a check-before-you-file summary. It does not generate a GST return and it does not produce a filing-ready JSON.
  • Nothing matches on tax names. Amounts are read from the Indian localisation's own tax tags and from Odoo's tax engine, the same code that produces the invoice totals.
  • Credit notes and debit notes are subtracted from the period rather than listed separately, because that is how they affect supplies.
  • Input tax credit is not split into eligible and ineligible: Odoo 19 Community records no ITC eligibility flag on a tax, so any split would be invented rather than read.
  • No government portal is ever contacted. Nothing leaves the database.

This module is a tool to assist with compliance workflows. Responsibility for statutory compliance rests with the user and their tax professional.
