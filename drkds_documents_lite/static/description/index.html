Document Folders (Lite)

A folder tree for company files, with tags, owners, linked records, expiry reminders and chatter mirroring, on Odoo 19 Community

Every company has files that belong to nobody's inbox: the shop licence, the office lease, the signed NDA, the ISO certificate, the scanned vendor bill. This module gives them a home. A file goes into a folder, carries tags, an owner, a contact and a link to the record it concerns, and can be given an expiry date that raises a to-do a week ahead.

Files already sitting in a chatter are filed with one action, or mirrored automatically for the models you choose. Nothing is copied: a document points at the ordinary Odoo attachment, so there is one file, in one place, with the usual access checks.

What it does

A folder tree with its own access

Folders nest as deeply as you like and show their full path. Each one names the groups that may see it and the groups that may file in it. A restricted folder, and everything in it, is invisible to anyone outside its groups.

Documents that know what they are

Name, folder, tags, owner, contact, a link to any record, notes and an expiry date. The type and size are read from the file. PDFs and images preview on the form; the Kanban shows image thumbnails and file-type icons for the rest.

Add to Documents

Select attachments in any attachment list, run the action, pick a folder and tags. The file is linked, not copied, and the document remembers which record and which contact it came from.

Chatter mirroring

Pick models in Settings. From then on, a file posted in the chatter of one of their records is also filed in a folder named after the model, linked back to the record, with the poster as owner.

Expiry reminders

An Expiring menu lists what lapses within seven days or already has. A daily job schedules a to-do for the owner, once per expiry date, so a renewal with a new date is reminded again when its turn comes.

Search that answers questions

Text search across name, notes and file name; filters for mine, linked, expiring, expired, images and PDFs; group by folder, owner, contact, linked model or expiry month. Searching a folder includes its sub-folders.

Good to know

  • Two access groups: a user sees the folders their groups allow; a manager sees everything and maintains folders, tags and the mirroring list.
  • Record rules enforce the visibility, so it holds in the API and in exports, not only in the interface.
  • A file uploaded through the form belongs to its document and goes with it. A file taken from another record stays with that record whatever happens to the document, and is never filed twice.
  • A new sub-folder starts with its parent's groups, so a restricted branch does not sprout an open leaf by accident.
  • Uninstalling keeps every file: uploaded files become plain attachments, mirrored files stay where they were.
  • Depends only on base and mail. Nothing else is dragged into your database.
  • The lite edition has no file versions, no share links, no request-a-file and no workflow actions on folders.
