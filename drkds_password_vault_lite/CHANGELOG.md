# Changelog

## 19.0.1.0.0 - 2026-09-15  First release.

- Models renamed to `drkds.lite.vault.entry`, `drkds.lite.vault.tag` and
  `drkds.lite.vault.access.log` before release. The previous names were the
  same as the paid drkds Credential Vault app, so the two shared database
  tables with different schemas and could not be installed together.
